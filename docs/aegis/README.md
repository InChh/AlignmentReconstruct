# Aegis Workspace

This directory stores durable design, baseline, work-continuation, and evidence records for AlignmentReconstruct.

- `baseline/`: snapshots of confirmed product and architecture boundaries.
- `specs/`: reviewed feature and architecture specifications.
- `work/`: resumable checkpoints and evidence for long-running implementation.
- `INDEX.md`: index of durable records.
- `BASELINE-GOVERNANCE.md`: rules for distinguishing requirement defects from implementation drift.
