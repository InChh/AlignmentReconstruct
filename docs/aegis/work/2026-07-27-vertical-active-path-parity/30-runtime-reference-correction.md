# 参考项目真实运行基线修正

## Change Necessity

- 用户已在参考项目的“拟合坡度参数设置”对话框中，用当前工作簿的 Z 列实际运行纵断面重构。
- 未勾选动态阈值范围，固定参数为：阈值 `0.001`、最小坡长 `350 m`、最大坡度代数差 `7‰`、上下行限坡 `25‰`、圆曲线、竖曲线半径整百。
- 实际结果保存在 `1.mdb` 的“基线坡度表”，线路名“既有基线”，共 `55` 个变坡点，里程范围 `0～49394.250344 m`。
- 当前库在同一组 1569 个投影里程/高程样本和同一参数下只输出 `2` 个控制点。因此现实现并非该次参考运行的算法迁移，必须修正。
- 旧工程当前未注释调用链表明该对话框执行 `CRebuildDlg` → `CReBuildGMX::FitSlope`。其中 `CountEstateFall` 使用前后超过 `15 m` 的测点、二阶差商绝对值乘 `100`，再与 `0.001` 比较；当前库的相邻三点且未乘 `100` 实现与之不一致。

## Patch Shape

- 保持 `VerticalReconstructor` 为唯一生产 owner，不新增并行算法。
- 以 `CReBuildGMX::FitSlope` 当前未注释的“方法三、原始”执行链为迁移权威，逐函数核对分类、拟合、合并、半径、震荡边界、里程与坡度整饰。
- 公共接口与 C++17/无 ARX、无 MFC 约束不变；仅补足参数语义和旧算法行为。
- 私有 XLSX、MDB 及其导出数据只作为本机外部夹具，不进入仓库。

## Pre-Claim Gate

- 在输出控制点数量不是 `55`，或不能按序与本次 `1.mdb` 的里程、高程进行小数点后误差验证前，不得声称纵断面迁移完成。
- 构建成功和合成测试通过只属于静态证据，不能代替真实数据逐点证据。
