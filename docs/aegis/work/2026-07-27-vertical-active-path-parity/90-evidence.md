## 依据旧活跃代码完成的修正

- `CountEstateFall`：分别向前、向后寻找里程差严格大于 `15 m` 的第一个测点，非等间距二阶差商取绝对值并乘 `100`。
- `FormSlopeAry`：交点除位于两直线有效范围外，还必须距前一直线起点超过最小坡长；最后一个交点距末测点必须超过 `200 m`。
- 震荡边界：恢复 `VPI ± R*tan(|Δα|/2)*cos(|坡角|)`，并应用前一竖曲线终点与后一变坡点限位。
- 整饰顺序：第二轮短坡合并前，把全部内部变坡点按设置归整，再合并归整后重合点。
- 半径拟合：保留旧迭代和向下归整，硬上限恢复为 `30000 m`。
- 默认纵面参数与本次参考对话框一致：阈值 `0.001`、最小坡长 `350 m`、限坡 `25‰`、最大坡差 `7‰`、竖曲线触发坡差 `3‰`、半径 `10000～30000 m`、半径整百、里程整十、坡度 `0.01‰`。
- `VerticalReconstructor` 仍是唯一生产 owner；没有引入 MDB 查询、硬编码控制点或第二套反演算法。
